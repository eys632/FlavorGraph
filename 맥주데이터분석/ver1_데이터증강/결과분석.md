# 실험 결과 (repeats = 3, 증강 비율 = 2×, 전문가 패널 데이터)

본 절에서는 **증강 데이터 수를 훈련 데이터의 2배로 설정**하고, **repeats = 3**으로 반복 수행한 최종 실험(v3)의 결과를 **요약 없이**, 가능한 한 **정확하고 자세하게** 기술한다.

모든 수치는 **3회 반복 실험의 평균(mean) ± 표준편차(std)** 로 보고한다.

---

## 1. 실험 설정 재확인

### 1.1 데이터 크기

- 전체 샘플 수: 250
- Train: 200
- Test: 50
- 입력 \(X\): 화학 성분 231개 feature
- 출력 \(Y\): 전문가 관능평가 50개 descriptor

### 1.2 증강 데이터 구성

- 증강 비율: 합성 데이터 = \(2 \times N_{\text{train}}\)
- 합성 데이터 수: 400
- 증강 학습 데이터 총량:
\[
N_{\text{aug}} = 200\ (\text{real}) + 400\ (\text{synthetic}) = 600
\]

### 1.3 반복 실험

- 서로 다른 random seed로 3회 반복
- 각 반복마다:
    - 맥주 스타일(beer style) 기준 층화 분할 유지
    - 동일한 전처리, 동일한 증강 비율, 동일한 평가 절차 적용

---

## 2. Phase 2: 예측 성능 결과 (Utility)

본 연구에서 **다운스트림 예측기(downstream predictor)** 로는

고차원·소량 데이터에서 안정적인 성능을 보이는 **GBDT(Gradient Boosting Decision Trees)** 를 주력 지표로 사용한다.

### 2.1 기준선(TRTR: Train on Real, Test on Real)

- GBDT 기준 TRTR 평균 성능:
    - 평균 \(R^2 \approx 0.1667\)

이는 “합성 데이터를 전혀 사용하지 않았을 때”,

이 데이터셋에서 달성 가능한 기준 성능이다.

---

### 2.2 TSTR (Train on Synthetic, Test on Real)

TSTR은 **합성 데이터만으로 학습했을 때 실제 데이터에 일반화가 가능한지**를 확인하는 지표다.

| 방법 | TSTR 평균 R² (GBDT) |
| --- | --- |
| Gaussian Copula | **+0.112 ± 0.026** |
| Bootstrapping | +0.111 ± 0.033 |
| VAE | -0.015 ± 0.005 |
| TabDDPM | -0.037 ± 0.025 |
| KDE | -0.057 ± 0.009 |
| CTGAN | -0.494 ± 0.060 |

### 해석

- Gaussian Copula는 **합성 데이터만으로 학습해도** 실제 테스트에서 양(+)의 \(R^2\)를 유지한다.
- Bootstrapping도 TSTR 성능은 양수이나, 이는 사실상 실제 데이터를 복제한 결과에 가깝다.
- VAE, TabDDPM, CTGAN은 TSTR 기준에서 음수 \(R^2\)를 보이며, 이는 “합성 데이터만으로 학습한 모델이 실제 데이터에 일반화되지 못함”을 의미한다.

---

### 2.3 AUG (Train on Real + Synthetic, Test on Real)

AUG는 **실제 데이터에 합성 데이터를 추가했을 때 성능이 향상되는지**를 직접적으로 측정하는 핵심 실험이다.

| 방법 | AUG 평균 R² (GBDT) | 증강 이득 ΔR² (=AUG − TRTR) |
| --- | --- | --- |
| VAE | **0.1836 ± 0.0087** | **+0.0169 ± 0.0141** |
| Gaussian Copula | 0.1751 ± 0.0204 | +0.0084 ± 0.0261 |
| TabDDPM | 0.1562 ± 0.0185 | -0.0104 ± 0.0218 |
| CTGAN | 0.1377 ± 0.0228 | -0.0289 ± 0.0257 |
| Bootstrapping | 0.1243 ± 0.0241 | -0.0423 ± 0.0253 |
| KDE | 0.1230 ± 0.0093 | -0.0437 ± 0.0149 |

### 해석

- **VAE는 평균적으로 가장 큰 증강 이득(ΔR² ≈ +0.017)** 을 제공한다.
- Gaussian Copula 역시 평균적으로는 양의 이득을 보이나, 표준편차가 커 반복에 따라 성능이 감소할 가능성도 존재한다.
- KDE, Bootstrapping, CTGAN, TabDDPM은 평균적으로 증강이 오히려 성능을 악화시킨다.

---

### 2.4 Descriptor(관능 항목)별 증강 이득 순위

각 관능 descriptor(총 50개)에 대해 “증강 이득(ΔR²)”을 기준으로 방법별 순위를 매긴 뒤, 그 순위를 평균낸 결과는 다음과 같다.

| 방법 | 평균 순위(avg rank, 낮을수록 우수) |
| --- | --- |
| VAE | **2.56** |
| Gaussian Copula | 2.90 |
| TabDDPM | 3.56 |
| CTGAN | 3.82 |
| Bootstrapping | 3.86 |
| KDE | 4.30 |

### 해석

- VAE는 개별 관능 항목 기준에서도 **상위권에 가장 자주 등장**한다.
- 이는 “일부 descriptor에서라도 합성 데이터가 실제 예측에 도움을 준다”는 증거다.

---

## 3. Phase 1: 모집단 적합성 및 구조 보존 (Fidelity & Validity)

Phase 2의 성능 결과만 보면 VAE가 가장 좋아 보일 수 있으나,

과학 데이터에서는 **분포 보존과 관계 구조 보존**이 반드시 함께 검증되어야 한다.

---

### 3.1 KS-test: 분포 보존

KS-test는 실제 데이터와 합성 데이터의 **분포 형태 차이**를 측정한다.

값이 작을수록 두 분포가 유사하다.

| 방법 | KS(X) 평균 | KS(Y) 평균 |
| --- | --- | --- |
| Bootstrapping | **0.0510 ± 0.0034** | 0.0472 ± 0.0023 |
| Gaussian Copula | 0.0533 ± 0.0036 | **0.0428 ± 0.0016** |
| KDE | 0.1571 ± 0.0015 | 0.1075 ± 0.0019 |
| CTGAN | 0.3555 ± 0.0030 | 0.3445 ± 0.0101 |
| TabDDPM | 0.3559 ± 0.0189 | 0.2369 ± 0.0061 |
| VAE | **0.5696 ± 0.0043** | **0.5380 ± 0.0093** |

### 해석

- Bootstrapping과 Gaussian Copula는 **화학(X)과 관능(Y) 모두에서 분포를 매우 잘 보존**한다.
- VAE는 X와 Y 모두에서 KS 값이 매우 커, **분포 자체가 크게 다르다**는 신호가 강하다.

---

### 3.2 PCD X–Y (Spearman): 화학↔관능 관계 보존

PCD X–Y는 **화학 성분과 관능 평가 사이의 관계 구조**가 얼마나 보존되었는지를 나타낸다.

Spearman 상관을 사용하여 단조 관계까지 반영하며,

Ledoit–Wolf shrinkage로 고차원·소량 환경에서도 안정적인 상관행렬을 계산한다.

| 방법 | PCD X–Y (Spearman) 평균 |
| --- | --- |
| Bootstrapping | **0.0381 ± 0.0002** |
| Gaussian Copula | **0.0416 ± 0.0006** |
| TabDDPM | 0.0902 ± 0.0111 |
| KDE | 0.1002 ± 0.0006 |
| CTGAN | 0.1051 ± 0.0009 |
| VAE | **0.6409 ± 0.0243** |

### 해석

- Bootstrapping과 Gaussian Copula는 **화학↔관능 상관 구조를 거의 그대로 유지**한다.
- VAE는 평균적으로 상관 구조가 크게 붕괴되었음을 의미하며,
이는 “예측 성능은 올릴 수 있지만, 과학적 관계 보존에는 심각한 문제가 있음”을 시사한다.

---

### 3.3 DCR: 복제(암기) vs 이상치(outlier)

DCR은 합성 샘플이 실제 데이터와 얼마나 가까운지/먼지를 거리로 측정한다.

| 방법 | DCR 비율(합성/실제) | 암기율(Real q05 기준) |
| --- | --- | --- |
| Bootstrapping | **0.026 ± 0.003** | **1.000 ± 0.000** |
| VAE | 0.731 ± 0.016 | **0.994 ± 0.004** |
| Gaussian Copula | 1.108 ± 0.006 | 0.005 ± 0.002 |
| KDE | 1.204 ± 0.008 | 0.000 ± 0.000 |
| TabDDPM | 1.207 ± 0.037 | 0.001 ± 0.001 |
| CTGAN | 1.242 ± 0.020 | 0.000 ± 0.000 |

### 해석

- Bootstrapping은 거리 거의 0에 가까운 샘플이 많아 **완전한 복제**임이 명확하다.
- VAE 역시 합성 샘플 대부분이 실제 샘플에 매우 가까워, **암기(memorization) 성향이 매우 강함**을 보인다.
- Gaussian Copula, KDE, CTGAN, TabDDPM은 암기율이 거의 0으로, 복제 위험은 낮다.

---

## 4. 종합 분석

### 4.1 성능(Utility)과 구조 보존(Fidelity)의 분리

- **VAE**
    - 증강 성능(ΔR²)은 가장 큼
    - 그러나 분포(KS), 관계 구조(PCD X–Y), 거리(DCR) 모두에서 **과학적 타당성은 크게 훼손**
- **Gaussian Copula**
    - 증강 성능은 중간 수준
    - 분포 및 화학↔관능 관계 보존이 매우 우수
    - 복제 위험도 낮음

### 4.2 해석적 결론

본 실험 결과는 **“유용성(성능 향상)”과 “타당성(관계 보존)”이 동일한 축이 아님**을 명확히 보여준다.

고차원·소량 과학 데이터에서는 딥 생성모델이 예측 성능을 소폭 향상시킬 수 있으나,

그 과정에서 **실제 화학↔관능 관계를 왜곡하거나 암기 기반 증강을 유발할 위험**이 존재한다.

반면, Gaussian Copula는 극적인 성능 향상은 없으나,

**분포·관계·거리 측면에서 가장 안정적이고 과학적으로 해석 가능한 합성 데이터**를 제공한다.

---

## 5. 논문 관점에서의 메시지

- **통계적 방법(Gaussian Copula)** 은 고차원·소량 환경에서
“과학적 구조 보존” 측면에서 강력한 기준선(baseline)이 될 수 있다.
- **딥 생성모델(VAE)** 은 “성능 향상”이라는 장점을 제공하지만,
그 결과를 해석할 때 **DCR 및 PCD X–Y 같은 구조 보존 지표와 반드시 함께 제시**되어야 한다.
- 따라서, 과학 데이터 증강에서는**“얼마나 성능이 오르는가”뿐 아니라
“무엇이 보존되고 무엇이 깨지는가”를 함께 평가하는 다면적 검증이 필수적이다.**



사실 이 end to end 과정은 LLM의 도움을 기반으로 진행하였기에 나의 주관적인 생각이나 의미있는 insight를 얻지 못하였음. 단지 이 연구의 전반적인 흐름을 빠르게 파악하기 위함에 의미가 있음.

이후 본격적으로 해야 할 작업은 data 자체애 대해서 매우 자세하고 엄밀하게 분석할 필요가 있다고 판단, 이를 진행하려고 한다.
